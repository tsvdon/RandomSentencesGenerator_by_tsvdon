# RandomSentencesGenerator_by_tsvdon
This is a random sentences generator that is run in the console:

- At start, the program generates 1 random sentence. It is made up of words and phrases from six different lists. One word is selected randomly from each list.
- Next, the user is given the option to choose how many fully unique sentences the program should generate - a whole number between 0 and 3. Fully unique means that if the user enters 2 or 3, no word in those 2 or 3 sentences will be repeated. Entering 0 ends the program.
